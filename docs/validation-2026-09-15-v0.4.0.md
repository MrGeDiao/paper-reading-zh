## 产物与格式核对

C5 的最终代码在两平台均实际执行。独立核对非均匀 softmax 与矩形输出：

- 输入含 2 个 query，value 维度为 3，输出应为 2×3。
- 两平台的非均匀权重结果均与解析计算在 `1e-12` 容差内一致；Codex 另用零 query 验证均匀权重。
- 使用浮点近似比较；首轮 Codex 自测曾因精确相等断言失败，改用近似比较后通过，代码未因此改动。该过程保留，未把一次失败的自测写成从未失败。

严格格式没有全部通过：

- 最终 Codex C4 在前置块之后补了一段原文数值冲突提醒；Claude C4 追加了继续展开的邀约。两者均没有展开完整深读，但超出了“只输出前置块”的严格形态。
- 最终 Codex C11 仍把简短结论放在材料范围之前。
- Claude C4 的总结为 219 个 Unicode 字符、131 个汉字。混合中英文的“150 字”计数口径尚需明确；本记录不擅自改写该约束，也不据此宣称长度严格通过。
