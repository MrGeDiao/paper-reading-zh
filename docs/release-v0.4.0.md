# paper-reading-zh v0.4.0

v0.4.0 精简了 Agent 入口，并修正阅读模式组合和多轮追问中的几处冲突。比如比较两篇 benchmark 并要求按表格顺序讲时，现在明确保留比较的开头和目标，不再夹入两份单篇深读模板。

## 本版变更

- **触发描述更短。** 从 826 字符缩到 152 字符，保留三类入口、按论文实现/复现意图和排除条件。详细词表留在正文，避免关键信息全部挤在长描述末尾。v0.3.0 曾记录 Codex 截短长描述的情况；本版用实际加载记录和正反用例检查路由。
- **完整模板集中维护。** 主入口保留阅读决策、通用证据规则和硬约束，完整主模式模板统一放在 `references/modes.md`。Web prompt 继续保持单文件自包含。
- **“看看”要有具体论文。** 已有论文时直接开始；没有标题、链接、PDF 或可继承上下文时，先问是哪篇。明确的工程拆解或比较要求仍决定模式。
- **组合使用时不换错模板。** 主模式决定前置块和任务目标，论文类型调整主体重点，图表等子开关调整组织方式。深读附加节“复现/应用提示”的省略条件不限制工程拆解主体，benchmark 的工程接入判断会保留。
- **追问可以继续使用已读原文。** 前提是原文在当前上下文中仍可核对。只有上轮回答或对话摘要时，需要重新读取原文或说明缺口，不能据此补表格数值或声称读过全文。
- **分段读取要如实说明。** 本轮实测发现，模型只读了 15 页 PDF 中的前 11 页，却声称读完全文。三入口已补充：材料范围以工具实际返回的页码或片段为准，读取成功或文件总页数都不能代替全文读取证据。

## 验证

本版扩展了人工回归清单：C1–C12 保留，C13–C18 覆盖无锚点阅读、模式组合与多轮材料来源，C4 补充实际已读页码的判定。另有 25 项声明式场景供维护时核对；场景文件通过静态校验，不等于全部完成实机测试。

首轮在 Codex、Claude Code 上均完成 C1–C18 及 C9S 对照。修正后，最终版完成 Codex **11/18**、Claude Code **8/18** 个主用例；两处实质问题已复测，剩余用例因额度限制未完成最终版验证。部分输出仍有格式偏差，网页端因未登录而未实测，不能宣称全平台完整通过。

逐平台结果、实际材料、运行方式及已知限制见 [v0.4.0 验证记录](./validation-2026-09-15-v0.4.0.md)。GitHub Release 附件只包含运行所需的 Skill 文件，验证材料与开发脚本不进入安装包。

## 升级

Agent 用户替换完整的 `paper-reading-zh/` 目录，并重启会话；需要保留 `references/` 与 `agents/`。Web 用户重新粘贴对应的 Project prompt。ChatGPT Skills beta 用户可使用 `paper-reading-zh-v0.4.0.zip`，该入口仍尚未完成首轮实机回归。

默认关键词不超过 5 个、每个不超过 8 个汉字或 3 个英文单词；总结不超过 150 字、基本信息 4 项、正文默认不超过 3500 中文字。平台状态仍按实际验证范围标注，不承诺所有客户端表现一致。
